# M1 common-path corpus — pypi
#
# 200 targets, the pypi half of the 400 that docs/15-corpora.md §3 specifies. Stratified by BUILD
# SYSTEM rather than by popularity, and sampled by prevalence within each stratum, because "an
# aggregate that hides a 20% rate on native extensions is not a number anyone can act on".
#
# Strata and their quotas:
#   50  flit_core or hatchling
#   60  setuptools configured through pyproject.toml
#   40  setuptools with setup.py only
#   30  poetry-core
#   20  maturin or a C extension: a platform wheel, not py3-none-any
#
# This is the corpus M1 quotes a reproduction rate from. The smoke corpus beside it is 20 targets
# of trivial utility packages and says nothing about the strata that do real work.
#
# **Every entry was fetched from the registry before it was written here.** A version that does not
# exist is not a failing target, it is a permanently depressed rate with no way to tell: the run
# reports it as unresolvable for ever and nobody rechecks a corpus. Selection proposed these and a
# separate pass confirmed all 200 resolve.
